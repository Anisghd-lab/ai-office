AI Office is an enterprise-grade autonomous multi-agent organization designed to run in a lightweight footprint on Android 16 ARM64 + Termux / Ubuntu 24.04 PRoot with an Android Native Control Center (Kotlin 2.0 + Jetpack Compose) featuring iOS-inspired Glassmorphism 2.0 aesthetics.

---

## The Human User ↔ AI CEO Governance Model

- **The Human User is NOT the CEO.** The user is exclusively the **OWNER / PRINCIPAL**.
- The **AI CEO (Nova Prime)** is the central autonomous executive intelligence running the organization.
- The Owner communicates exclusively with the **AI CEO** via the Android application.
- The **AI CEO** autonomously directs 8 specialized departments:
  - **Research & Intelligence** (Dr. Aris Vance)
  - **Technology & Engineering** (Marcus Sterling)
  - **Marketing & Communications** (Elena Rostova)
  - **Finance & Economic Guardrails** (Cassian Drake)
  - **Operations & Workflow Logistics** (Tariq Benali)
  - **Creative & Visual Studio** (Lyra Silvers)
  - **Strategy & Growth Governance** (Kaelen Thorne)
  - **Human Resources & Workforce Optimization** (Sora Tanaka)
- **Human Owner Reserved Powers**: While internal decisions, research, task creation, and scheduling are executed autonomously by the AI CEO, all consequential external operations (social publishing, spending, messaging, connecting/disconnecting accounts) strictly require **MANDATORY USER APPROVAL**.

$$\text{HUMAN OWNER / PRINCIPAL} \longrightarrow \text{AI CEO} \longrightarrow \text{DEPARTMENTS} \longrightarrow \text{AI CEO} \longrightarrow \text{HUMAN OWNER}$$

## Key Pillars

1. **Mandatory User Approval Gateway**:
   Default-deny external action policy. The AI CEO can plan, discuss, analyze, and synthesize internally. Consequential external operations require cryptographic authorization from the Human Owner via the Android Control Center.

2. **100% Free / Freemium Only**:
   Strict zero-cost operational boundary. No paid subscriptions, no paid LLMs, no credit card billing.

3. **Genuinely Native Android Experience**:
   No WebView, no Flutter, no React Native. Built with modern Kotlin 2.0, Jetpack Compose, Material 3 Glassmorphism 2.0, Coroutines, StateFlow, Kotlin Serialization, and real-time Server-Sent Events (SSE) connected to `127.0.0.1`.

4. **Self-Healing Dynamic Agent Architecture**:
   Persistent department directors manage dynamic specialist subagents with lifecycle tracking, task conflict resolution, shared memory, and automatic recovery across backend restarts.

5. **Official Social Media Integration**:
   Standard PKCE OAuth workflows for TikTok, Facebook, and Instagram with preview rendering, strict payload validation, and User-gated publication.
